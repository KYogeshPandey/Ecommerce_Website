# ShopEase — Full-Stack E-commerce Website

A modern full-stack e-commerce platform built with **React, Node.js, Express, and MongoDB**, featuring a responsive cyber-glassmorphism UI, authentication, product browsing, shopping cart, checkout, and admin management.

🚀 **Live Demo:** https://ecommerce-website-gold-chi.vercel.app/

## Features

- 🔐 User Authentication (Login/Register)
- 💡 Interactive Lamp Authentication UI
- 🛍️ Product Browsing & Search
- 🛒 Shopping Cart
- 💳 Checkout & Payment Integration
- 📦 Order Management
- 👨‍💼 Admin Dashboard
- 🗄️ MongoDB Atlas Integration
- 📱 Responsive Design
- ✨ Modern Cyber-Glassmorphism UI
